What this is measuring

The detector flagged 52 one-second windows as calls with near-total confidence, but the hand labels say “noise”. No acoustic measure separates them from real calls — not spectral flatness, not pitch strength, not peak loudness. So either the model is wrong about all 52, or those are real calls nobody annotated. Listening is what settles it.

Judging only the model's errors would measure nothing, though: there would be no comparison and knowing they are errors biases the ear. So 36 loudness-matched controls are mixed in — windows whose label and model score already agree, half call and half not. Everything is shuffled and unlabelled, this page included. The answer key lives in a separate local file.

Afterwards the question is a rate comparison: if the flagged windows get called “call” about as often as the known calls, they are missed annotations and detection precision was understated. If they track the known non-calls, they are real mistakes.

Audio is peak-normalised so quiet calls stay audible, which means the player says nothing about loudness — the measured dB is printed instead. The cyan lines mark the exact second under judgement inside two seconds of context.
