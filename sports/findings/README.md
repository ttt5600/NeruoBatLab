# fund findings

when money depends on it) has tried to break it. Front matter: id, question (Q00x from ../QUESTIONS.md), status
(confirmed | open | refuted), date, sources, critic, and the gate verdict from
`../.venv_quant/bin/python scripts/fund_stats.py verdict <strategy>`. Refutations are kept.

Results before 2026-10-27 live in notes/EDGES_AND_AGENTS.md, lab/ledger.jsonl and lab/lockbox.jsonl; they are not
copied here.
